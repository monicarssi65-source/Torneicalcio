# ⚽ Tornei Calcio Giovanili - App Android

App Android offline per gestire tornei di calcio giovanili.
Database SQLite locale — funziona senza internet.

## Come ottenere l'APK

1. Vai su **Actions** in questo repository
2. Clicca sull'ultimo workflow **"Build APK"**
3. Scarica l'artifact **TorneiCalcio-debug**
4. Estrai lo zip → installa `app-debug.apk` sul telefono
